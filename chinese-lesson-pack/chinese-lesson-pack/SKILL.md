# Комплект материалов по уроку китайского

## Зачем это

Пользователь готовится к **письменному** экзамену по урокам 1–8: перевод в обе стороны, грамматика, иероглифы от руки, вопросы по текстам. Материалы живут в `C:\Users\Mechrevo\Documents\Китайский_экзамен` и питают сразу четыре вещи: печатные прописи, всплывающий тренажёр `trainer.pyw`, настольное приложение `Китайский.pyw` и веб-версию (артефакт + автономный HTML для пересылки).

Всё это читает одни и те же простые текстовые файлы. Поэтому оформить урок = положить в папку правильные файлы и пересобрать веб. Приложения новые уроки подхватывают сами.

## Что должно получиться на урок N

| Файл | Содержимое |
|---|---|
| `Урок_NN_конспект.md` | слова таблицей, грамматика с примерами, ключевые фразы |
| `Урок_NN_слова.txt` | по строке на слово: `иероглифы⇥пиньинь⇥перевод⇥разбор частей` |
| `Урок_NN_предложения.txt` | `слова через пробел⇥перевод` для конструктора фраз |
| `Прописи_урок_NN.pdf` | генерируется скриптом из словника |
| раздел в `Тексты_уроки_*.md` | диалоги в три строки + разбор + вопросы с ответами |

NN всегда двузначный (`Урок_05_слова.txt`). Урок `00` это «К экзамену»: слова сверх учебника, замеченные в прошлогоднем тесте (`Прошлогодний_тест.md`).

## Как читать урок из PDF

Учебник лежит в `C:\Users\Mechrevo\Downloads\U_Chzhunvey_-_Sovremenny_kitayskiy_yazyk_Uchebnik.pdf`. Текстового слоя в нём нет, `pdftoppm` не установлен, поэтому страницы рендерятся в PNG через PyMuPDF и читаются как изображения:

```python
import fitz
d = fitz.open(путь_к_учебнику)
d[i].get_pixmap(dpi=110).save(f"L_{i:03d}.png")   # dpi 110 достаточно, 150+ раздувает контекст
```

Соответствие: **страница книги N = индекс PDF N+14** (0-based). Начала уроков: 1 → с.11, 2 → с.20, 3 → с.27, 4 → с.36, 5 → с.44, 6 → с.53, 7 → с.62, 8 → с.73. Читай подряд: заголовок, «Слова и выражения», «Дополнительные слова», «Тексты», «Комментарии», «Грамматика», «Расширенный запас слов». Если пользователь прислал фото или страницы сам, бери их и в PDF не лезь.

## Словник: четвёртая колонка

Разбор на части это не украшение, а основной способ запоминания для этого пользователя: иероглиф запоминается как сумма знакомых кусков. Пиши коротко и по делу, называя смысловые части и фонетик:

```
好	hǎo	хороший	女 женщина + 子 ребёнок = хорошо
妈妈	māma	мама	女 + 马 mǎ-фонетик
笔	bǐ	ручка	竹 бамбук + 毛 шерсть: кисть
休息	xiūxi	отдыхать	休 человек у дерева 木; 息 = 自 нос + 心 сердце
```

Полезно отмечать: ключ-смысл (氵 вода, 讠 речь, 钅 металл, 艹 трава, 亻 человек), фонетик с его чтением, пиктограммы, упрощения (`发` от `發`). Если знак не раскладывается, так и напиши: «пиктограмма трёх пиков».

Слово из нескольких знаков разбирай целиком, но кратко; прописи всё равно разложат его по знакам.

## Прописи

```bash
python <skill>/scripts/propisi.py Урок_05_слова.txt Прописи_урок_05.pdf "Прописи. Урок 5. 能不能试一试"
```

Скрипт сам берёт данные о чертах из `Documents\Китайский_экзамен\data\graphics.txt` (набор Make Me a Hanzi). Если файла нет, знак печатается шрифтом без почертной строки, и скрипт сообщает, каких знаков не хватило: тогда скачай `graphics.txt` из репозитория `skishore/makemeahanzi`, спросив разрешение у пользователя.

Формат страницы менялся по просьбам пользователя и сейчас такой: слева слово крупно с пиньинем и переводом, над клетками строка почертного написания (в каждом квадрате добавляется одна черта, новая красным), ниже две строки клеток 田字格, первые две клетки первой строки с серым образцом. Не «улучшай» этот макет без просьбы.

## Предложения для конструктора

Токены разделяются пробелами, ими же задаётся правильный порядок. Разбивай по смысловым единицам, а не по знакам: `我 不 是 林 老师 。` Знаки препинания (`。？！`) выноси отдельным токеном. Бери фразы прямо из диалогов урока и из грамматических примеров, 12–18 штук на урок. Каждая фраза должна проверять грамматику урока, а не просто быть набором слов.

## Тексты

Файлы `Тексты_уроки_1-4.md` и `Тексты_уроки_5-8.md`. Формат жёсткий, потому что его разбирает сборщик веб-версии:

```markdown
## Урок 5. Текст 1 (в магазине)

小姐: 哟，您会说汉语?
Yō, nín huì shuō Hànyǔ? О, вы говорите по-китайски?

**Разбор:** 会 умение, 能 возможность. 太…了 «слишком».

**Вопросы к урокам 5:**
1. 那件白衬衫多少钱?
Ответы: 1. 四百二十八块。
```

Правила, на которые опирается парсер: заголовок урока начинается с `## Урок N`; строка с иероглифами это китайская реплика; следующая строка «пиньинь + перевод» (кириллица начинается не раньше 4-го символа) показывается как подпись, её можно скрывать переключателями; строки со `**` это комментарий.

## Пересборка тренажёра

```bash
python <skill>/scripts/build_web.py --rotation 0,1,2,3,4
```

Скрипт складывает в папку материалов три файла: `Ханьюй-тренажёр.html` (автономный, с объявленной кодировкой, viewport, меткой версии и перехватом ошибок), `index.html` (та же копия под GitHub Pages) и `hanyu_artifact.html` (без внешнего каркаса, для публикации артефактом).

`--rotation` перечисляет уроки, которые подмешиваются в карточки при фильтре «Все». Пользователь просил не подсовывать ему уроки, которые он ещё не начал: держи в ротации только пройденное, остальные уроки остаются доступны выбором вручную. Тот же список продублирован в `trainer.pyw` (константа `LESSONS`) — правь оба места вместе.

Публикация веб-версии: `Artifact` с файлом `hanyu_artifact.html`. Артефакт уже существует, поэтому обновляй его тем же URL, а не создавай новый: https://claude.ai/code/artifact/6802a0b7-23b6-411c-8dcd-29f2c515ba24 (в чужой сессии передавай его параметром `url`).

## Что отдать пользователю

Отправляй файлами конспект, прописи и (если менялся) файл текстов; про веб пиши, что обновлён по прежней ссылке. В конце давай мини-тест на 8–10 пунктов по свежему уроку: перевод в обе стороны, пропуски (счётные слова, 还是/或者, 在/给), «найди ошибку». Ответы пользователь пишет иероглифами; **пиньинь с тонами от него не жди** — у него нет способа набирать диакритику, тоны подписываешь ты сам.

Разбирая его ответы, показывай не только верный вариант, но и правило урока, из-за которого ошибка возникла.

## Мелочи, которые экономят время

- В чате и файлах не используй длинное тире и обороты вида «важно отметить».
- Сначала простой вариант, без потока перегенераций: пользователь этого просил прямо.
- Приложения `trainer.pyw` и `Китайский.pyw` запускаются двойным кликом благодаря строке-шебангу с путём к Python 3.10 в первой строке файла: не удаляй её, иначе системный лаунчер выберет Python 3.14 без нужных библиотек, и окно молча не откроется.
- Автономный HTML на айфоне не работает во встроенных просмотрщиках (они режут JavaScript), там нужен настоящий браузер или страница по ссылке; метка версии в шапке помогает быстро понять, открыта ли свежая копия и жив ли скрипт.
